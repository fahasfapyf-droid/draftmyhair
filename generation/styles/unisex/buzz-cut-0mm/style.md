Create a true 0.0 mm buzz cut produced with a zero guard clipper.

The result must immediately read as:

FRESHLY BUZZED

It must NOT read as:

• clean bald
• razor shaved
• completely hairless scalp
• painted scalp
• artificial follicle texture

The defining characteristic is extremely short visible stubble with clearly perceptible follicular density.

Maintain approximately 0.0 mm zero-guard stubble across all clipped scalp regions.

The visible hair should remain extremely short.

Allow only microscopic natural variation in apparent length caused by:

• growth direction
• follicle orientation
• local lighting
• natural hair-fibre variation

Do not create areas that appear completely hairless.

Do not create areas that appear substantially longer than zero-guard stubble.

The result must remain visibly different from a clean shave.

• dot grids
• repeated patterns
• uniform spacing
• synthetic stippling
• procedural noise

The scalp should feel like real human skin containing thousands of naturally distributed short hair fibres.

STYLE DISTINCTION — BUZZ VS BALD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The result must visibly distinguish itself from the Bald engine.

BALD:

No visible hair.

BUZZ 0.0 MM:

Visible follicular stubble remains.

If the result looks completely hairless:

→ restore subtle follicular visibility.

If the result looks like obvious longer stubble:

→ reduce apparent fibre length.

If the result looks like a grey scalp:

→ restore individual follicular structure and natural skin variation.

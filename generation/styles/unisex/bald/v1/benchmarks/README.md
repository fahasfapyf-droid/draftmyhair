# Bald / Clean Shaved — Benchmarks

This directory contains actual production benchmark results.

Do not fabricate scores.

Each benchmark should record:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• scalp realism
• follicle realism
• background integration
• edge integration
• overall realism
• observed defects
• final decision

The v1 specification must remain unchanged after testing.

Experimental modifications require a new version.

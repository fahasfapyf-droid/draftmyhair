# Old Money Bob — Benchmarks

This directory contains actual production benchmark results.

Do not fabricate scores.

Each benchmark should record:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• ear preservation score
• earring preservation score
• chin-length accuracy
• side-part accuracy
• C-curve accuracy
• salon finish
• overall realism
• observed defects
• final decision

The v1 specification must remain unchanged after testing.

Experimental modifications require a new version.

# SOFT LAYERED BOB
# Draft My Hair Style Engine — v1

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STYLE TARGET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create a genuine modern Soft Layered Bob.

The defining characteristics are:

• short bob length
• chin to slightly-below-chin perimeter
• rounded balanced silhouette
• soft internal layering
• diffused perimeter
• natural inward movement
• controlled lightweight structure

The hairstyle must immediately read as a short layered bob.

It must NOT read as:

• Italian Bob
• Structured Blunt Bob
• Soft Layered French Bob
• Lob
• Bixie
• Pixie
• Shag
• helmet bob

The haircut should appear naturally cut and naturally worn.

It must never appear heavily styled or sculpted.

HAIR COLOR — ROOT AUTHORITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Determine intrinsic hair colour exclusively from the original root zone.

Read approximately the first 2–3 mm emerging from the scalp across
visible:

• frontal hairline
• temples
• part
• crown

Ignore environmental colour influence from:

• lighting
• clothing
• background
• reflected surroundings

Reproduce the exact intrinsic source colour throughout the haircut.

Preserve only natural tonal variation already present.

Do not:

• invent highlights
• increase saturation
• warm the colour
• cool the colour
• change the colour family
• introduce artificial gloss
• introduce colour gradients

LENGTH CONTROL — PRIMARY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hair must terminate between:

CHIN
and
SLIGHTLY BELOW CHIN

No strand may extend to:

• shoulder
• collarbone
• upper chest

All original length beyond the defined boundary must be removed.

This is a shortening transformation.

The final silhouette must unmistakably read as a short bob.

LAYER DISTRIBUTION — THREE ZONE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The haircut is organized into three structural regions:

1. Crown
2. Mid-Length
3. Ends

Each region must perform a distinct role.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CROWN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The crown remains controlled and relatively flat.

Hair follows the natural growth direction.

Maintain close contact with the skull.

No:

• artificial lift
• puffing
• crown expansion
• inflated volume
• sculpted crown

The crown must preserve the source skull geometry.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
MID-LENGTH — PRIMARY LAYERING ZONE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Soft internal layering begins through the mid-length region.

The layers should create:

• natural movement
• controlled weight reduction
• subtle dimensionality
• realistic strand overlap

Layering must blend continuously.

Do not create:

• visible step cuts
• layer shelves
• disconnected sections
• choppy transitions

The layering should be visible through natural movement rather than
obvious geometric lines.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The perimeter must be diffused rather than blunt.

Allow subtle feathering and micro-texture.

The edge must never become:

• ruler straight
• mathematically clean
• hard
• blunt

Individual strand groups may terminate at slightly different
positions while preserving the overall bob silhouette.

Create a rounded and balanced silhouette.

The shape should follow natural skull curvature.

Avoid:

• boxy structure
• triangular expansion
• excessive width
• helmet shape
• mushroom shape
• stacking

Front sections may remain slightly longer than the rear while
transitioning naturally toward the face.

The front-to-side transition must be seamless.

No visible break between sections.

Maintain natural movement.

No:

• curtain bangs
• heavy fringe
• blunt fringe
• deliberate forehead sweep

Allow a subtle inward tendency.

The inward movement must not be uniform.

Some sections may remain neutral.

Some may bend slightly inward.

A small number may settle slightly outward.

Each section should respond independently to:

• weight
• length
• gravity
• direction
• neighbouring strands

Do not create:

• repeated curvature
• identical bends
• salon curls
• artificial shaping

The haircut should look naturally fallen rather than blow-dried.

STYLE DISTINCTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ITALIAN BOB:

→ heavier
→ denser
→ stronger weight
→ polished inward blowout

SOFT LAYERED FRENCH BOB:

→ chin level
→ lighter
→ more breathable
→ more Parisian
→ softer perimeter

SOFT LAYERED BOB:

→ chin to slightly below chin
→ rounded balanced shape
→ clearly layered mid-length structure
→ diffused perimeter
→ natural inward tendency

This engine must remain between the shorter French Bob and the
heavier Italian/structured Bob architectures.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SELF-CORRECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If the result reads as Italian Bob:

→ reduce density and weight.
→ remove excessive polish.

If the result reads as French Bob:

→ allow slightly more length below chin.
→ restore a more conventional layered-bob structure.

If the result reads as Blunt Bob:

→ soften and diffuse the perimeter.
→ restore internal movement.

If the result reads as Lob:

→ shorten the perimeter.

If the result reads as Bixie:

→ restore sufficient lower bob weight.

If the result reads as Shag:

→ reduce texture and disconnected layering.

If the result reads as Helmet Bob:

→ reduce crown and side volume.

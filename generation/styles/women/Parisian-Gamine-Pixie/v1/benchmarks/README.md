# Parisian Gamine Pixie — Benchmarks

This directory contains actual generation benchmarks.

Do not fabricate scores.

Each benchmark should record:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• haircut accuracy
• fringe accuracy
• realism score
• observed defects
• final decision

Experimental changes require a new style version.

The v1 specification should not be silently modified after testing.

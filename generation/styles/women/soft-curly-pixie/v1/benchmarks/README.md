# Soft Curly Pixie — Benchmarks

This directory contains actual production benchmark results.

Do not fabricate scores.

Each benchmark should record:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• pixie architecture score
• curl accuracy
• curl realism
• hair integration
• overall realism
• observed defects
• final decision

The v1 style specification must remain unchanged after testing.

Experimental modifications require a new version.

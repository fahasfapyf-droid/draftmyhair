architectural perimeter.

• density

STYLE DISTINCTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BLUNT LOB

→ collarbone-to-shoulder length
→ strong continuous perimeter
→ substantial lower weight
→ minimal visible layering
→ restrained movement

SOFT LOB

→ softer perimeter
→ lighter weight
→ more movement
→ less architectural

ITALIAN BOB

→ shorter
→ denser
→ more rounded
→ stronger blowout behaviour

FRENCH BOB

→ shorter
→ lighter
→ more breathable
→ softer perimeter

BUTTERFLY CUT

→ pronounced layers
→ substantial face framing
→ cascading movement

LONG LAYERS

→ visible layered structure
→ preserved long length
→ softer weight distribution

The Blunt Lob must remain visually distinct from all of these.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SELF-CORRECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If the result reads as Soft Lob:

→ strengthen the perimeter.
→ increase lower-edge density.
→ reduce movement.

If the result reads as Italian Bob:

→ reduce volume.
→ lengthen to true Lob proportions.
→ remove rounded blowout behaviour.

If the result reads as French Bob:

→ restore Lob length.
→ increase lower weight.

If the result reads as Butterfly Cut:

→ eliminate visible layers.
→ remove face-framing separation.

If the result reads as Long Layers:

→ eliminate internal layering.
→ restore continuous perimeter.

If the result reads as grown-out hair:

→ strengthen the blunt cutting line.
→ equalize visual termination height.

If the perimeter becomes too artificial:

→ introduce microscopic fibre-level variation without weakening
the overall continuous line.

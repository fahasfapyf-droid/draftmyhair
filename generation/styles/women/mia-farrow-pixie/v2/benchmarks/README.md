# Mia Farrow 1968 Pixie — Benchmarks

This directory contains actual generation benchmarks.

Do not fabricate scores.

Each benchmark must contain:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• haircut accuracy
• realism score
• observed defects
• final decision

The v2 style specification is considered locked.

Any new experimental prompt should receive a new version rather than modifying v2.

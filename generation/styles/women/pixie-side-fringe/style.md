SIDE FRINGE — PRIMARY DEFINING FEATURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create a clear diagonal side fringe.

The fringe begins from a defined side part and sweeps diagonally
across the forehead.

The direction must be unmistakable.

The fringe should graze one eyebrow only.

It must not extend below the eyebrow.

The fringe remains:

• semi-transparent
• wispy
• lightweight
• naturally separated

Maintain visible air gaps between selected strand groups.

The fringe must follow directional movement.

It must never fall straight downward.

→ compact sides

→ diagonal eyebrow-grazing fringe

→ quieter

SELF-CORRECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If the result reads as Bixie:

→ shorten the sides and lower perimeter.
→ remove bob-like fullness.

If the result reads as Long Pixie:

→ shorten the crown and sides.

If the fringe falls straight down:

→ restore clear diagonal directional flow.

If the fringe becomes a heavy bang:

→ reduce density and restore transparency.

If the result reads as Parisian Gamine Pixie:

→ strengthen the defined side part and diagonal fringe.

If the result reads as Mia Farrow Pixie:

→ restore directional fringe movement and slightly more crown length.

If the result reads as Bob:

→ shorten the lower perimeter and tighten the sides.

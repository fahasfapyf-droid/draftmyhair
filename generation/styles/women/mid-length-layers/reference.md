# Mid-Length Layers — Reference Specification

REFERENCE PURPOSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Define the visual architecture of a modern mid-length layered haircut.

The source photograph remains authoritative for:

• identity
• face
• pose
• camera
• lighting
• background
• framing
• natural hair colour
• original part

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PRIMARY REFERENCE CHARACTER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The hairstyle should demonstrate:

• collarbone-to-upper-chest length
• visible internal layering
• soft face framing
• reduced lower weight
• natural gravity-driven ends
• moderate natural volume
• realistic strand behaviour

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REFERENCE INTERPRETATION

References may inform:

• layered architecture
• relative length
• weight distribution
• face-framing structure
• natural strand behaviour

Do not transfer:

• facial identity
• skull geometry
• camera angle
• pose
• lighting
• background
• hair colour

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
REFERENCE PROHIBITIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Avoid references dominated by:

• long layered hair
• blunt bobs
• lobs
• shag cuts
• wolf cuts
• heavy bangs
• curtain fringe
• extreme blowouts
• heavily curled styling
• editorial texture

MID-LENGTH LAYERS

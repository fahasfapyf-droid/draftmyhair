# Sleek-Back Pixie — Benchmarks

This directory contains actual production benchmark results.

Do not fabricate scores.

Each benchmark should record:

• source image
• generated image
• model
• prompt version
• generation date
• identity score
• pose score
• geometry score
• ear preservation score
• pixie accuracy
• backward-flow accuracy
• surface-tension score
• fibre realism
• overall realism
• observed defects
• final decision

The v1 specification must remain unchanged after testing.

Experimental modifications require a new version.

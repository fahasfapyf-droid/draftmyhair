Create a refined feminine Sleek-Back Pixie.

The defining characteristic is controlled backward directional flow.

The hairstyle must immediately read as:

TRUE PIXIE
+
BACKWARD FLOW
+
CONTROLLED SURFACE TENSION
+
CLOSE SKULL-FOLLOWING SILHOUETTE

The visual character comes from disciplined direction rather than
volume, curls, or heavy styling product.

The hair should appear naturally swept backward.

It must NOT read as:

• Bixie
• Bob
• Undercut Pixie
• Spiky Pixie
• Wet-Look Pixie
• Gelled Editorial Slick-Back
• Helmet Pixie
• Fluffy Pixie

HAIR COLOR — ROOT AUTHORITY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Determine intrinsic hair colour exclusively from the original root
zone.

Read approximately the first 2–3 mm surrounding the scalp across
visible:

• frontal hairline
• temples
• part
• crown
• nape

Ignore environmental colour influence from:

• background
• clothing
• reflections
• ambient colour
• lighting colour casts

Preserve the perceived overall darkness and intrinsic tonal
character of the original hair.

Warm sunlight may create localized specular highlights only where
physically supported by the source lighting.

Never reinterpret reflected light as intrinsic hair colour.

Do not:

• lighten the hair
• darken the hair
• warm the hair
• cool the hair
• invent highlights
• increase saturation
• introduce artificial gloss

Under neutral lighting, the hairstyle must read as the same
intrinsic hair colour as the source.

DIRECTIONAL FLOW — PRIMARY DEFINING FEATURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hair flows backward from the frontal hairline toward the crown.

The direction begins naturally at the front hairline and continues
through the crown.

The movement must be:

• unified
• controlled
• directional
• physically believable

It must not appear mechanically combed.

Allow localized variation between neighbouring strand groups.

The overall backward direction must remain unmistakable.

Hair should appear guided by natural tension rather than rigid
styling.

→ true pixie proportions

→ close skull-following silhouette
→ refined feminine character

MIA FARROW PIXIE:

→ shorter

→ more static

→ lighter
→ airier
→ micro-fringe
→ less backward tension

→ visible diagonal fringe
→ defined side part

UNDERCUT PIXIE:

→ strong crown/undercut contrast

SELF-CORRECTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If the result reads as Wet-Look Pixie:

→ reduce surface compression and shine.
→ restore visible fibre structure.

If the result reads as Gelled Slick-Back:

→ introduce natural localized strand variation.
→ reduce product-like surface tension.

If the result reads as Spiky Pixie:

→ soften strand separation.
→ restore unified backward flow.

If the result reads as Fluffy Pixie:

→ reduce volume.
→ bring hair closer to the skull.

If the result reads as Bixie:

→ shorten the sides, nape, and lower perimeter.

If the result reads as Side-Fringe Pixie:

→ reduce lateral directional emphasis.
→ restore unified backward movement.

If the crown becomes inflated:

→ reduce crown height while preserving directional flow.

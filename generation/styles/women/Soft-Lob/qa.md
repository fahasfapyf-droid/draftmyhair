# Soft Lob — QA Specification

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PRIMARY STYLE TEST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

At normal viewing distance the result must immediately read as:

TRUE SOFT LOB

with:

• true Lob length
• softened perimeter
• invisible internal layering
• gentle movement
• refined face framing

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LENGTH CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• collarbone-to-upper-shoulder length
• true Lob proportions
• coherent front/sides/back length
• no Bob shortening
• no long-layer extension

FAIL:

• Bob
• French Bob
• Italian Bob
• long layered haircut
• grown-out hair

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PERIMETER CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• continuous Lob outline
• soft point-cut edge
• microscopic variation
• no ruler-straight digital edge

FAIL:

• hard blunt line
• excessive feathering
• wispy transparent perimeter
• broken silhouette
• shag-like edge

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAYER CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• internal layers invisible at normal distance
• gradual weight release
• no step cuts

FAIL:

• obvious cascading layers
• Butterfly Cut
• Long Layers
• disconnected sections

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FACE FRAMING CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• begins between chin and collarbone
• blends into perimeter
• natural part respected

FAIL:

• curtain framing
• dramatic face framing
• isolated long front pieces

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
MOVEMENT CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• soft
• gravity-driven
• natural
• restrained

FAIL:

• rigid/frozen hair
• excessive blowout
• dramatic waves
• editorial styling

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DENSITY CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASS:

• medium density
• healthy fullness
• sufficient lower-edge weight

FAIL:

• Italian Bob density
• Butterfly Cut lightness
• transparent ends
• excessive thinning

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
IDENTITY / GEOMETRY CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Verify:

• face unchanged
• skin unchanged
• expression unchanged
• jaw unchanged
• chin unchanged
• ears unchanged
• neck unchanged
• head position unchanged
• head tilt unchanged
• camera unchanged
• perspective unchanged
• framing unchanged
• crop unchanged
• zoom unchanged

Any failure = automatic fail.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HAIR COLOR CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• original intrinsic hair colour
• original perceived darkness
• no environmental contamination
• no reference colour transfer
• no artificial colour shift

→ unmistakable Soft Lob

Soft Lob haircut.

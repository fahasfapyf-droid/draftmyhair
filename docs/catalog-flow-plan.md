# Draft My Hair — Catalog Flow Plan

Status: planning only

## Target flow

Upload → Audience (Women / Men / Unisex) → Service → Category → Style cards → Preview

## Services

- HAIRSTYLE / haircuts
- HAIR_COLOR
- BUZZ_CUT
- BALD
- BEARD
- BEARD_REMOVAL

## Rules

1. Do not invent production prompt engines.
2. A selectable style must map to an existing production prompt key.
3. UNISEX styles may appear for both Women and Men where appropriate.
4. Haircut/hairstyle cards must be grouped by their database category.
5. Service and gender selection must remain URL/session compatible with the existing generation flow.
6. Existing verified production prompt content must not be modified as part of catalog UI work.

## Current verified production engines

The current production prompt registry contains 21 verified engines. The catalog must remain synchronized with that registry until additional engines are independently finalized.
